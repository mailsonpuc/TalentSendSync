# TalentSendSync

Este projeto é uma aplicação pessoal para gerenciamento de currículos enviados para oportunidades de trabalho.

A ideia central é centralizar e organizar os cadastros de currículos, acompanhar o status de cada candidatura e manter um histórico de contatos e movimentações relacionadas às vagas.

## Objetivo

- cadastrar currículos enviados
- controlar candidaturas por posição ou empresa
- acompanhar o histórico de contato com recrutadores
- visualizar informações gerais do processo seletivo em um painel
- manter uma rotina simples e prática para gestão de oportunidades

## Stack

- .NET / ASP.NET Core para a API
- Entity Framework para acesso a dados
- SQL Server para persistência
- React + Vite no frontend

## Observação

É um projeto pessoal, desenvolvido para facilitar o acompanhamento de currículos enviados e melhorar a organização da busca por emprego.
